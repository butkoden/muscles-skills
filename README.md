# Muscles Engineering Skills

Engineering skills for AI agents working with the Muscles framework, Python, and React. This repository contains reusable guidance documents; it is not a Python package and is not published to PyPI.

## Skills

- `muscles-engineering` — architecture, package boundaries, runtime, data, integrations, and framework-specific engineering practices.
- `python-engineering` — Python implementation, typing, testing, and maintenance practices.
- `react-engineering` — React and TypeScript component, state, accessibility, and UI engineering practices.

## Layout

```text
muscles-engineering/
  SKILL.md
  references/
    muscles-models.md
    openapi-swagger.md
python-engineering/
  SKILL.md
react-engineering/
  SKILL.md
```

Each skill is defined by its `SKILL.md`. Keep its references beside the skill so relative links continue to work.
